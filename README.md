# Refrimathy — servicio técnico en Bogotá

## Archivos del sitio

- `index.html`: página, estilos, interacciones, etiquetas para buscadores y datos estructurados.
- `robots.txt` y `sitemap.xml`: acceso e índice del sitio para buscadores.
- `refrimathy-logo.png`: recurso gráfico de marca disponible para el sitio.

Las fotografías se cargan desde Pexels y requieren conexión a internet. Los archivos `styles.css` y `script.js` son recursos de la versión anterior y ya no se cargan desde la página actual.

## Publicación e indexación

El sitio publicado es `https://refrimathy.netlify.app/`. Para que Google pueda indexarlo, el propietario debe verificar ese dominio en [Google Search Console](https://search.google.com/search-console/), enviar `https://refrimathy.netlify.app/sitemap.xml` y solicitar la indexación de la página de inicio. La aparición en Google puede tardar; el sitemap facilita el rastreo, pero no garantiza ni el plazo ni la posición en los resultados.

Como negocio que atiende a domicilio, también conviene crear o reclamar un Perfil de Negocio de Google y configurar el área de servicio en Bogotá, sin publicar una dirección residencial si no se atiende al público en ella.

## Confirmar antes de cambiar el sitio

Si el sitio cambia de dominio, configura una redirección permanente desde el dominio anterior siempre que esté disponible y actualiza la URL canónica, Open Graph, datos estructurados, `robots.txt` y `sitemap.xml`. Verifica también el tiempo de experiencia, el teléfono, el correo, la cobertura y los servicios antes de publicar cambios futuros.
